# Проверка сдаваемой версии

Дата: 2 ноября 2026 года. Python 3.11.9. Реальная модель: `nvidia/nemotron-3.5-super-vl:free`.

## Автоматические проверки

`python -m pytest -q`: **48 passed**. Ключи и сеть в тестах модели не используются.

Проверены: неверный JSON и типы, повторные ключи, пустые поля, размер ввода, точные цитаты и пробелы, сохранение назначения, конфликты, неизвестные ссылки, числа и единицы, подмена свойства при том же числе, границы заголовка/описания, статус частичного результата, ограниченное исправление и блокирование неподтверждённой продажи/учебного назначения.

HTTP-ветка проверена на контролируемых ответах: 400, 401, 402, 403, 404, 429, 500, тайм-аут, оборванный ответ и неверный JSON. Тесты интерфейса проверяют обычную форму, заполнение примера, отсутствие переключателя режимов, конфликт и отсутствие ключа. Дополнительно проверены закрытый доступ без секрета, отказ неверному паролю, правильный вход, выход с очисткой сессии и хеширование с солью. Проверены командный запуск `--help` и наличие описаний новых функций.

В локальном окружении сторонний плагин anyio выдаёт одно предупреждение о будущем переименовании класса pytest; проверки проходят. Это предупреждение не является ошибкой проекта.

## Реальные запросы

| Полный манометр | Заголовок 57 символов; описание 805; 4 поисковых фразы; формат и смысловая проверка пройдены; 3 API-вызова |
| Полный преобразователь | Заголовок 57 символов; описание 851; 4 поисковых фразы; формат и смысловая проверка пройдены; 3 API-вызова |

| Противоречие | Генерация остановлена: показаны диапазоны `0–1,6 МПа` и `0–2,5 МПа`, требуется уточнение |

Источник проверки — вымышленные учебные товары по согласованию с заказчиком, поскольку полные данные двух обещанных товаров в исходном PDF отсутствуют. Входы и результаты находятся в `examples/`; это настоящие ответы API с программной сборкой commercial-блока, а не имитация модели.

Сводки: `examples/live_evaluation.json`, `examples/live_edge_checks.json`. Повторение: `python scripts/evaluate_live.py --edge-cases`. Повторный запуск расходует бесплатную квоту и перезаписывает результаты.

Вручную сверены числовые значения, назначение, аудитория и основные утверждения двух полных описаний с учебными источниками. Смысловую проверку выполняет та же модель, поэтому она не является независимой гарантией; все карточки остаются черновиками для менеджера.

## Запуск и публикация

Локальный Streamlit запущен на `127.0.0.1:8501`; HTTP health возвращает 200. Ранее проверено скачивание настоящего ответа через браузер. Интерфейс остаётся тёмным, с четырьмя полями и одной основной кнопкой.

Ключ хранится в локальном `.env`, исключённом из Git и ZIP. Перед публикацией выполняется `python scripts/check_secrets.py`: проверяются файлы Git-индекса, включая известные форматы токенов и приватных ключей, без вывода значений. GitHub Actions повторяет эту проверку и тесты без секретов. Результаты CI доступны во вкладке Actions репозитория.

У бесплатных серверов наблюдались 429 и обрывы ответа при включённых рассуждениях. Рассуждения отключены; платные модели и платный fallback запрещены. Доступность следующих запусков зависит от сервера и оставшейся бесплатной квоты.
