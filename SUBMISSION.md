Подготовил прототип AI-помощника для карточек контрольно-измерительных приборов.

Репозиторий: https://github.com/dddnnnlll/product-card-assistant

Приложение: https://card-assistant-dddnnnlll.streamlit.app/

Пароль доступа передаётся в личном сопроводительном сообщении.

Реализованы простая форма Streamlit, реальная генерация через бесплатную LLM в OpenRouter, экспорт текста/JSON/Markdown и командный запуск. Характеристики сохраняются из входа, извлечённые факты связаны с цитатами. Проверяются длина, числа, единицы и смысловые утверждения; при ошибках допускается одна правка, после которой непроверенный результат блокируется. Неполные данные отмечаются явно, конфликтующие значения требуют уточнения.

В README описаны установка, промпты, архитектурные решения и ограничения. Для двух полных учебных товаров сохранены реальные ответы модели с описаниями 805 и 851 символ. Также проверены неполный ввод и противоречие диапазонов.

В PDF отсутствовали полные данные двух обещанных товаров, поэтому по согласованию использованы явно обозначенные вымышленные примеры. Решение остаётся инструментом подготовки черновика: семантическая проверка моделью не заменяет проверку контент-менеджером.

Основные сложности — доступность бесплатных серверов и соблюдение моделью объёма без добавления характеристик. Для этого добавлены ограничения схемы, программные проверки, отдельная смысловая проверка и ограниченное исправление ответа.
