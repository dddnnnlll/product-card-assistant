# AI-помощник для описаний товаров

Создаёт черновик карточки прибора по его характеристикам и исходному описанию.

**[Открыть приложение](https://card-assistant-dddnnnlll.streamlit.app/)** — пароль указан в сообщении со ссылкой. Устанавливать программу и вводить API-ключ для проверки не нужно.

## Как пользоваться

1. Войдите по паролю.
2. Нажмите **«Заполнить пример»** или введите свой товар. Название обязательно, остальные поля можно оставить пустыми.
3. В характеристиках указывайте по одному параметру на строку: `Питание: 24 В`.
4. Нажмите **«Создать описание»** и дождитесь ответа.
5. Проверьте текст и нажмите **«Скачать описание»**.

В блоке под результатом доступны характеристики, поисковые фразы, текст для менеджера и экспорт JSON/Markdown. Другие учебные примеры находятся в **«Настройках»**.

## Что получается

- SEO-заголовок до 70 символов.
- Описание на 800–1200 символов, если исходных данных достаточно.
- Таблица характеристик, 3–5 поисковых фраз и краткий текст о назначении товара и его аудитории.

При нехватке сведений приложение отмечает пропуски и выдаёт частичный черновик. При противоречиях просит уточнить данные. Готовый текст нужно проверить перед публикацией.

## Запуск на своём компьютере

Нужны **Python 3.11** и [API-ключ OpenRouter](https://openrouter.ai/settings/keys).

**1. Скачайте проект и установите зависимости** — команды для PowerShell на Windows:

```powershell
git clone https://github.com/dddnnnlll/product-card-assistant.git
cd product-card-assistant
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

**2. Настройте доступ.** Откройте `.env` и вставьте API-ключ после `OPENROUTER_API_KEY=`. Затем создайте хеш пароля входа:

```powershell
.\.venv\Scripts\python.exe scripts/password_hash.py
```

Введите придуманный пароль длиной от 12 символов. Скопируйте выведенный хеш в `.env` после `APP_PASSWORD_HASH=` без кавычек. При входе используйте сам пароль.

**3. Запустите приложение:**

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

Откройте [localhost:8501](http://localhost:8501). На macOS/Linux замените `.\.venv\Scripts\python.exe` на `.venv/bin/python`, а `Copy-Item` на `cp`.

## Как устроено

**Python · Streamlit · Pydantic · OpenRouter.** Используются только бесплатные модели с суффиксом `:free`; по умолчанию — `nvidia/nemotron-3.5-super-vl:free`.

Приложение извлекает факты, создаёт текст и проверяет его. Характеристики сохраняются из входа, извлечённые сведения привязаны к цитатам. Код проверяет длину, числа и единицы, отдельный запрос к модели — смысл. При ошибке допускается одна правка, затем непроверенный результат блокируется. Промпты: [card_assistant/prompts.py](card_assistant/prompts.py).

Бесплатная модель может отвечать медленно или временно отклонять запросы из-за лимитов. Проверка той же моделью не гарантирует точность. Введённые сведения передаются OpenRouter и провайдеру модели. API-ключ и хеш пароля хранятся в `.env` или секретах Streamlit и не публикуются в Git.

Возможные улучшения: независимая проверка второй моделью, больше тестов на реальных товарах и редактирование извлечённых фактов перед генерацией.
